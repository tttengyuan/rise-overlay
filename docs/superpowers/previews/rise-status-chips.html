改造前这两行是一整条灰色字符串——ViewModel 里 string.Join 拼好的， XAML 拿到的只是个 string，没法给其中某两个字单独上色。
现在 ViewModel 额外暴露一份结构化集合（原有字符串属性原样保留），HUD 才能画成分段色块。
色块 = 左侧 2px 语义色条 + 标签（语义色）+ 数值（前景色）。承载容器是 WrapPanel， 超宽自动换行，绝不溢出 300px。激活态（异常生效中 / 晕眩中 / 御龙中）标签加粗。
