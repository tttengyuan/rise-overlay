# Rise 专用叠层 HUD — 设计文档

**日期：** 2026-08-31  
**状态：** 已确认；实现计划见 `docs/superpowers/plans/2026-08-31-rise-overlay.md`  
**产品名（暂定）：** Rise Overlay / 崛起叠层  
**关联：** 从 [HunterPie](https://github.com/HunterPie/HunterPie) 抽取 Rise 专用能力，UI 重做；与「崛起百科」Flutter App 数据同源思路（静态弱点表可复用 mhrice / 百科导出）。

---

## 1. 目标与成功标准

### 1.1 目标

为《怪物猎人：崛起 / 破晓》提供**轻量、可吸附游戏窗口**的桌面叠层，战斗中一眼看到：

- 怪物血量 / 虚弱捕获线 / 部位破坏与断尾  
- 属性弱点与推荐属性  
- 愤怒 / 晕眩进度 / 耐力 / 倒地等状态  
- 怪物异常积累（毒麻眠爆减气等）  
- 猎人 DPS 与总伤（单人 / 最多 4 人组队）  

接任务后、进图前自动弹出**任务简报**（静态弱点与可捕/断尾信息）。

### 1.2 成功标准

| 标准 | 说明 |
|------|------|
| 信息正确 | 血量、捕获阈值、部位破坏、异常、伤害统计与游戏内存一致（以 HunterPie Rise 读取能力为基线） |
| 占地小 | 默认左上一体面板宽度约 260–280px；DPS 区显著矮于怪物卡 |
| 可读 | 弱点/推荐无晃眼动效；部位属性带「弱」防误导为吸收 |
| 窗口模式可用 | 叠层吸附游戏窗口，移动/缩放跟随 |
| 范围可控 | V1 不含猎人药/技能 Buff、翔虫、玩家自身血耐 HUD |

### 1.3 非目标（V1 不做）

- 完整移植 HunterPie 全游戏 / 全 Widget  
- 猎人异常托盘（鬼人药、金刚等）  
- Discord / 任务导出 / 花结等外围功能  
- 多套配装存档式「方案库」（叠层侧）  
- 自定义皮肤编辑器（仅内置紧凑青灰主题）

## 2. 范围

### 2.1 功能模块

1. **任务简报（Quest Briefing）** — 接取狩猎任务后自动弹出  
2. **战斗怪物面板（Monster HUD）** — 进图后显示，目标怪实时数据  
3. **伤害统计（DPS）** — 贴在怪物面板下方  
4. **壳层** — 进程附着、窗口吸附、显示/隐藏热键、基础设置  

### 2.2 实现路线（已选）

**瘦身 Fork HunterPie（推荐方案）**

- 保留 Rise 内存读取 / 怪物 / 异常 / 伤害计量核心  
- 删除 World / Wilds 及其他无关 Widget  
- 用新的紧凑 WPF（或现有技术栈内）UI 替换默认 Monster / Damage Widget  

备选（未选）：薄封装调 Core；从零读内存（周期长、易碎）。

## 3. 信息架构与界面

### 3.1 视觉原则

- **紧凑动效 HUD**：一体小面板，左上默认，可拖拽  
- **青灰色系**，避免金色强闪  
- **弱点 / 推荐：静止**，无呼吸/脉冲（与其它信息一致）  
- **推荐**：无边框；文案「推荐」+ 与弱点行同款属性色块；并列最高属性全部进入推荐  
- **属性色块文字：白色**  
- **部位属性**：前缀「弱」+ 色块，表示该部位属性肉质最高（**非吸收**）；并列可多个  
- **血条下状态**：一行文字，无进度条块  

### 3.2 任务简报

**触发：** 接取含大型目标的任务后自动显示；进打猎地图后切换为战斗 HUD。

**布局（方案 B 分块 + A 单块内容）：**

```
任务简报                    目标 ×N
─────────────────────────
怪名（可截断）
弱 [五属色块]     推荐 [色块…]
[可捕获/不可捕] [断尾?] [重点部位]
───（多目标虚线分隔，重复块）───
```

- 多目标同一面板内分块，上限按已知 **4**（怪异调查）  
- 推荐算法：取该怪综合/代表肉质五属性最大值集合；并列全进推荐  
- 芯片：可捕获 | 断尾（无可断则弱化/隐藏）| 重点部位短标  

**数据：** 任务目标怪物 ID + **静态表**（无需进图）。

### 3.3 战斗怪物面板

自上而下：

1. **可捕获横幅**（仅可捕且已过虚弱线）：文案「可捕获」+ 面板描边脉冲（青）  
2. **标题行**：怪名（方案1 截断）+ 可选「不可捕」标 + 血量百分比  
3. **弱点行**：`弱` + 五属（亮/淡）+ `推荐` + 色块（静止）  
4. **血条**：当前/最大隐含于百分比与可选数字行；**虚弱竖线**（可捕怪，无倒三角）  
5. **数字行**：`当前/最大`；已过线时「已过虚弱线」  
6. **状态一行文字**（无条块）：  
   - 常驻示意：`愤怒 0:14 · 晕眩 88% · 耐力 62%`  
   - 有则插入：`晕眩中 0:03`、`倒地 0:02`  
   - 愤怒：倒计时；晕眩：距触发进度 %（触发中改为计时）；耐力：%；倒地：计时  
7. **部位区**：  
   - 图例：`弱× = 属性弱点（非吸收）`  
   - 每行：`部位名` + `[断]`/`[破]` + `弱`色块… + 细条 + `当前/最大` 或「已破坏」  
   - 可切断部位强调「断」标签与切断条色  
8. **异常区**：  
   - **不含晕眩**（晕眩只在血条下状态行）  
   - 与部位**同款扁行**；**仅显示有积累（>0）或触发中**的：毒 / 麻 / 眠 / 爆 / 减气等  
   - 触发中可用字「触发」代替 %  

**多目标战斗：** 每只当前相关怪可叠多张卡，或只显示锁定目标（实现计划中定默认：优先锁定/最近交战目标，可切换）。

### 3.4 DPS 区（怪物卡正下方）

**单人（一行）：** `DPS 186 · 总伤 42180`

**组队（最多 4 人，扁行）：**

```
队伍                    合计 110940
1 我   ━━━━━  172  42180
2 阿飞 ━━━━   141  34520
...
```

- 列：序号 · 名 · 占比条 · 即时 DPS · **总伤**（最醒目）  
- 自己行高亮  
- 高度须明显紧凑，避免「比怪物卡还胖」  

### 3.5 窗口与交互

- **吸附游戏窗口**（已选）：窗口模式移动/改大小时 HUD 相对游戏客户区保持  
- 可拖拽微调相对偏移；设置里可重置  
- 热键：显示/隐藏叠层（具体键位实现时定，可默认参考 HunterPie）  
- 简报可手动关闭；再次打开可热键或托盘

## 4. 数据与逻辑

### 4.1 实时（进图后，HunterPie Rise 管线）

| 数据 | 用途 |
|------|------|
| 怪物 HP 当前/最大 | 血条、百分比 |
| 捕获阈值 / 是否可捕获 | 虚弱线、横幅、简报芯片 |
| 部位 break / sever HP | 部位行 |
| 愤怒计时 | 状态行 |
| 晕眩积累与触发 | 状态行（不进异常列表） |
| 耐力 | 状态行 |
| 倒地等硬直 | 状态行（有则显示） |
| 异常积累（毒麻眠爆减气…） | 异常扁行 |
| 玩家伤害计量 | DPS / 总伤 / 占比 |

### 4.2 静态表（简报 + 弱点/推荐/部位弱属性）

| 数据 | 来源建议 |
|------|----------|
| 怪名、图标 | 本地化表 / 百科导出 |
| 五属肉质（分部位） | monsters 肉质；推荐=最大值集合 |
| 可断尾 | parts sever 字段 |
| 可捕获 | 种类规则（古龙/霸主等不可捕）+ 任务类型 |

百科 `monsters.json` 的 `hitzones` / `parts` 可作为静态源之一，与运行时 ID 映射。

### 4.3 推荐属性算法

1. 选定代表肉质行（如头部状态1，或各部位加权——V1 用**头部或「总体」行**，实现时与数据表对齐并写死规则）。  
2. 在火/水/冰/雷/龙中取最大值 `M`。  
3. 所有等于 `M` 且 `M > 0` 的属性进入「推荐」。  
4. 天彗龙类并列四属全部推荐；单峰则只显示一个色块。  

部位「弱」色块：对该部位五行取最大值集合，同样规则；UI 前加「弱」字。

## 5. 架构（逻辑组件）

```
┌─────────────────────────────────────────┐
│  App Shell（托盘、设置、热键、窗口吸附）   │
└─────────────┬───────────────────────────┘
              │
     ┌────────▼────────┐
     │  Game Session    │  检测 Rise 进程 / 任务状态
     └────────┬─────────┘
              │
   ┌──────────┼──────────┐
   ▼          ▼          ▼
 Quest     Monster     Damage
 Briefing  Tracker     Meter
 (static+  (live HP/   (party
  quest)    parts/ail)  DPS)
   │          │          │
   └──────────┼──────────┘
              ▼
        Overlay View
     (Briefing | Combat+DPS)
```

**边界：**

- `Game Session`：是否在任务中、是否已进图、目标怪 ID 列表  
- `Monster Tracker`：只暴露 UI 需要的 DTO（血量、部位、状态行、异常列表）  
- `Damage Meter`：每人 id/名/dps/total/share  
- `Overlay View`：纯展示 + 拖拽；不读内存

## 6. 错误与降级

| 情况 | 行为 |
|------|------|
| 未启动游戏 | 托盘提示；无叠层或显示「等待游戏」 |
| 游戏中但无任务 | 隐藏战斗/简报 |
| 静态表缺某怪 | 弱点/推荐显示「—」；实时血量仍可用 |
| 不可捕怪 | 无虚弱线、无捕获横幅；简报「不可捕」 |
| 读内存失败 / 版本偏移 | 明确错误提示；避免显示过期数值 |
