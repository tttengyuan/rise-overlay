## Purpose

Rise Overlay aims to be a **Monster Hunter Rise-only** compact HUD overlay focused on:

- Monster HP
- Parts
- Ailments
- DPS

It is intentionally narrower in scope than full HunterPie (multi-game client / full feature set).
